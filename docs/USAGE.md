# 使用说明

1. 安装 APK。已有本项目版本时覆盖安装，不要先卸载；覆盖升级要求包名和签名相同。
2. 保留原版 WhatsApp，连接自己的 VPN，并确保多开空间被纳入其路由。
3. 在“网络与定位”选择仅 VPN 或住宅代理，填写自己的代理配置、保存并检测。
4. 新建并打开空间，在 WhatsApp 内自行登录。
5. 空间“…”菜单支持重启、重命名、桌面快捷方式和删除。删除会清除对应空间本地数据，操作前有确认。

原版更新后可以手动同步，也可以开启自动同步等待后台检查；执行时机受系统调度影响。

打不开时先看启动阶段和网络检测结果，再尝试“…”→“重新启动空间”。仍失败请记录版本、时间与操作步骤；不要在公开 Issue 粘贴密码、手机号、验证码或聊天内容。

IP 定位使用出口 IP 的估算位置，不等于精确 GPS。当前 TCP 转发未支持 UDP，不保证语音、视频或全部流量路径。关闭住宅模式后仍保留上次加密保存的配置。
